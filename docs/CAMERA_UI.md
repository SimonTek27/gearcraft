# Camera UI

Layout ispirato a **Windows Fotocamera** + **Impostazioni fotocamera Windows 11**:

| Zona | Contenuto |
|------|-----------|
| Alto | Titolo, selettore dispositivo, stato + tab **Attrezzatura** / **Effetti** |
| Centro | Anteprima a tutto stage, badge LIVE |
| Basso | Segment Foto / Video / **QR**, pulsante scatto, Avvia/Arresta |
| Destra | Card impostazioni: Dispositivo, Video, Foto, Regolazioni immagine |

## Tab

- **Attrezzatura** — cattura e device (layout Win11)
- **Effetti** — pipeline effetti; se "Usa come sorgente principale" è ON, le app vedono il feed elaborato come fotocamera virtuale

Niente griglia di pulsanti sparsi: controlli raggruppati in card.
