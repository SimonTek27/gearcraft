# UI palette (Sonar-inspired)

Inspired by SteelSeries Sonar EQ/preset screen: **layered blue-gray**, not flat pure black.

| Role | Hex | Use |
|------|-----|-----|
| Window | `#1a1d26` | App background |
| Deep inset | `#14171f` | Grooves, title |
| Panel | `#222632` | Sidebars, strips |
| Card | `#2a2f3c` | Channel cards, tiles |
| Elevated | `#323844` | Hover / pressed |
| Border | `#3c4252` | Subtle edges |
| Muted text | `#9aa1b0` | Labels |
| Body text | `#e8ebf2` | Primary |
| Accent | `#00e7a0` | Selection, Game tab, CTAs |
| Stream path | `#ff6b6b` | Streamer fader |

EQ handles (preset screen reference): multi-color dots per band (purple→green spectrum).
